# DayPulse

Plan the output you expect from today, check in every hour, and see how you're improving week over week. Works on **Android**, **Windows** and the **web**, all in sync.

- **Web app:** https://gamernishant.github.io/daypulse/
- **Downloads:** [latest release](https://github.com/GamerNishant/daypulse/releases/latest): `DayPulse-v1.0.apk` (Android) and `DayPulse-Setup-1.0.0.exe` (Windows)

Use one account everywhere. On your phone and PC, DayPulse shows today's targets when you unlock, and it reminds you hourly on whichever device you're using. A check-in on any device resets the reminder clock everywhere.

See [DESIGN.md](DESIGN.md) for how it's built and [FLOW.md](FLOW.md) for how the code runs.
